# Метод, из которого сделан прототип

Ответы на пять вопросов тренера. Из них выведены функции FitWatch.

1. **Почему человек приходит?** Называет цель (вес, форма, здоровье), но держит его другое: ощущение энергии и уважения к себе. → Показываем прогресс и самочувствие, а не только цифры.
2. **Что сбивает с графика?** Первые 2–3 недели: усталость, скука, нет заметного результата, слишком тяжёлые занятия. И главное — эффект «пропустил день, значит всё потеряно». → Серия переживает день отдыха; есть «лёгкий день».
3. **Что возвращает?** Лёгкий вход (короткая версия), отсутствие вины, маленькая победа, личное сообщение. → «Минимум дня» (10 минут растяжки, засчитывается), тон советов по профилю.
4. **Что мешает масштабировать?** Внимание тренера одному клиенту: помнить состояние каждого. → Ежедневный отзыв на минуту и профиль, который считается сам.
5. **Что автоматизировать?** Минутный отзыв → выявить риск срыва → подобрать нагрузку и тон. Это и есть движок (`engine.js`).

## Что в прототипе соответствует
- Отзыв за день и обратная связь (понравилось / не понравилось / идея) → экран «Отзыв», выгрузка файлом.
- Профиль (Спринтер, Уставший, Ищущий новизны, Ровный бегун) → правила в `engine.js`, без ИИ.
- Совет дня по самочувствию и паузам → главная.
- Видео упражнений, план по дням, баллы и серия → программы.
- Стретчинг → программа «Стретчинг и восстановление».
- Питание → дневник калорий, ориентировочные значения.
- Тренер → вопросы-ответы по правилам.

## Что осознанно не сделано
- Нет аккаунтов и сервера: всё в браузере пользователя.
- Профиль — оценка по правилам, не психологический диагноз.
- Тренер не ИИ: отвечает заготовленными ответами. Свободные тексты разбираются вручную через выгрузку отчёта.
- Калории приблизительные, не медицинские рекомендации.

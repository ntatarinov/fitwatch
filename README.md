# FitWatch — прототип

Локальный прототип приложения для тренировок: видео упражнений, план по дням, баллы и серия, ежедневный отзыв, профиль по правилам, дневник питания (с подсказкой по фото), стретчинг, тренер-диалог по дереву решений.

**Запуск:** `./serve.sh`, затем http://localhost:8080 (нужен интернет для видео YouTube; на телефоне в той же сети — http://<адрес-компьютера>:8080).

**Показ заказчику:** Профиль → «Загрузить демо» заполнит две недели данных, и сразу видны профиль, советы и серия.

## Что добавлено в версии 0.2 (итерация 1)
- **Анкета и цель** (`#/me`): цель, уровень, дни и минуты, место, ограничения, параметры для питания. Подбор плана по правилам (`planner.js`), раздел «Мой план» (`#/plan`).
- **Каталог упражнений** (`#/library`, 39 упражнений): мышцы, оборудование, уровень, вид; поиск и фильтры; схема тела, где мышцу выбирают нажатием (`body.js`, `catalog.js`). Видео к 38 упражнениям, ролики внешние (YouTube); техника описана общими словами и требует проверки тренером.
- **Питание с БЖУ** (`nutrition.js`, `#/food`): 53 продукта на 100 г (значения справочные), расчёт по массе, правка массы, ориентир на день по анкете. Подсказка по фото теперь с БЖУ и правкой продукта и массы.
- **Дизайн «заряд» (версия 0.3):** живой фон, стеклянные карточки, кольцо недели и огонёк серии на главной, шкала уровня (7 уровней), 10 достижений, праздник с конфетти и звуком за тренировку, уведомления об уровнях и достижениях. Звуки синтезируются в браузере (`fx.js`, без файлов), кнопка 🔊 в шапке выключает звук; при «уменьшить анимацию» в системе движение отключается.
- Автоматические тесты: `npm test` (логика: каталог, подбор, питание, схема тела). Проверка интерфейса в имитации браузера: `test-ui/flow.js` (66 проверок).
- Не сделано в этой версии: аккаунты и сервер, тренеры, тарифы, челленджи, учёт сна, взвешивания и графики, раздел «без инвентаря», офисные разминки, рецепты и остальные идеи второго списка.

## Версия 0.4: сервер, аккаунты, рейтинг (шаг 2A)
По просьбе Айдархана (переписка 31.10): база, данные пользователя (вес и рост) с бонусами и рейтингом. Тренеры и подписки идут следующими шагами.

- **Что работает:** регистрация и вход (пароли scrypt, сессии в cookie `HttpOnly`, ограничение попыток), вес и рост с историей и графиком, очки и бонус за серию на сервере (20 очков, растяжка 10; +5 с третьей тренировки подряд, +10 с седьмой; одна тренировка в день), рейтинг за неделю, месяц и всё время (только для тех, кто включил участие), перенос истории из браузера при регистрации, удаление аккаунта со всеми данными.
- **Как устроено:** одна серверная функция `api/index.js` (адреса /api/* направляет `vercel.json`) (на бесплатном тарифе их не больше 12), правила в `api/_lib/app.js`, схема и миграции в `api/_lib/schema.js`, база Neon (Postgres). Без базы сайт работает как раньше, а страницы аккаунта показывают «сервер ещё подключается».
- **Как подключить базу (один раз):** Vercel → проект `fitwatch` → Storage → Create Database → Neon → Connect Project. Vercel сам добавит `DATABASE_URL`; секреты в код и в чат не нужны. Таблицы создаются при первом запросе.
- **Защита:** изменения только с заголовком `X-FW` и своим Origin; пароли и сессии в базе только в виде хэшей; в рейтинге видны только имя и очки и только по согласию; вес, рост и самочувствие видны только владельцу.
- **Ограничения:** почта не подтверждается; очки в рейтинге считаются только по тренировкам, записанным в аккаунте (при регистрации переносятся последние 30 дней); оплата не подключена. Данные о здоровье: до выхода к настоящим пользователям из Казахстана нужно проверить требование о хранении персональных данных на серверах в Казахстане.
- **Проверка:** `npm test` (70 тестов, сервер проверяется на настоящем Postgres в памяти, нужен `npm i --no-save @electric-sql/pglite`), `npm run test:ui` (интерфейс в имитации браузера и сквозная проверка с базой, нужен `npm i --no-save jsdom @electric-sql/pglite`).

## Версия 0.5: тренеры, переписка, тарифы, закрытые программы, сон (шаги 2B и 2C)
- **Тренеры:** заявка тренера, подтверждение администратором, запрос клиента (нужен тариф «Персональный тренер»), кабинет тренера, чат. Тренер видит данные клиента только по его согласию: цели и ограничения, результаты и замеры включаются отдельными переключателями и отзываются в любой момент. Тренер не ставит диагнозы и не назначает лечение, это написано в интерфейсе.
- **Тарифы:** бесплатный, «Премиум», «Персональный тренер». Оплата не подключена: тариф выдаётся промокодом (`#/tariffs`). Промокоды создаёт администратор (`#/admin`).
- **Закрытые программы:** 4 расширенные программы на 4–8 недель с ростом нагрузки по неделям. Содержимое хранится только на сервере (`api/_lib/programs.js`) и отдаётся по тарифу, у бесплатного пользователя его нет даже в ответе сервера. Это черновики, их должен проверить тренер.
- **Сон:** журнал сна; если сна меньше 6 часов, совет дня предлагает лёгкую тренировку (`#/sleep`).
- **Настройка администратора (один раз):** в Vercel (Settings → Environment Variables) добавить `ADMIN_EMAILS` с вашей почтой (несколько через запятую) и выложить заново. Без неё некому подтверждать тренеров и создавать промокоды.
- **Проверка:** `npm test` (78 тестов), `npm run test:ui` (три сквозных сценария: интерфейс → сервер → база). Нужно: `npm i --no-save jsdom @electric-sql/pglite`.

## Версия 0.6: вход через Telegram
- **Как работает:** кнопка «Войти через Telegram» (виджет Telegram). Сервер проверяет подпись данных секретным токеном бота (`api/_lib/telegram.js`), создаёт аккаунт без почты и пароля или входит в существующий. Вход по почте остаётся запасным. Уже вошедший человек может привязать Telegram к своему аккаунту, тогда оба способа открывают один аккаунт.
- **Настройка (один раз):** в Telegram `@BotFather` → `/newbot`, затем `/setdomain` с адресом сайта (`fitwatch-six.vercel.app`). В Vercel (Settings → Environment Variables) добавить `TELEGRAM_BOT_TOKEN` (токен, секрет, в чат не отправлять) и `TELEGRAM_BOT_USERNAME` (имя бота без `@`). Для администратора по Telegram: `ADMIN_TELEGRAM_IDS` (числовые идентификаторы через запятую; свой можно узнать у бота `@userinfobot`). Затем выложить заново.
- **Безопасность:** подпись проверяется постоянным по времени сравнением, данные действуют сутки, попытки ограничены; токен нигде не отдаётся странице. Удаление аккаунта без пароля требует слова УДАЛИТЬ.
- **Дальше:** бот сможет присылать напоминания и уведомления о сообщениях тренера (право писать запрашивается при входе); мини-приложение внутри Telegram.
- **Проверка:** `npm test` (78 тестов), `npm run test:ui` (четыре сценария). Настоящий вход через Telegram проверяется на живом сайте после настройки бота.

## Как устроено
- `data.js` — программы, упражнения, ответы тренера. Видео — id ролика YouTube.
- `catalog.js`, `planner.js`, `nutrition.js`, `body.js`, `pages.js` — каталог, подбор плана, питание с БЖУ, схема тела, новые страницы.
- `achievements.js`, `fx.js` — уровни и достижения; звуки, конфетти, уведомления.
- `engine.js` — движок профиля и советов (правила, без ИИ), чистые функции.
- `tree.js` — движок дерева диалога тренера; само дерево — `TRAINER_TREE` в `data.js`. Следующий вопрос и формулировки зависят от пройденного пути, варианты скрываются по состоянию пользователя, есть «Назад».
- `photo.js` — эксперимент «калории по фото»: модель MobileNet в браузере (загрузка с CDN, ~15 МБ при первом использовании), без сервера и API.
- `app.js` — страницы и действия, данные в localStorage браузера.
- `METHOD.md` — метод тренера, из которого выведены функции.

## Правила
- Основные баллы: +20 за «Я потренировался» (+10 за растяжку), одна тренировка в календарный день.
- +5 за просмотр видео: засчитывается при ≥ 80% проигранного (перемотка не считается).
- Серия: перерыв между тренировками не больше 2 дней.
- Профиль считается с 3 отзывов за последние 14 дней.

## Тесты и ограничения
- Дерево проверяется на целостность (`Tree.validate`): нет битых ссылок, циклов и недостижимых узлов.
- Фото: модель знает общие продукты (фрукты, овощи, пицца, бургер), не знает плов, бешбармак, баурсаки и не определяет порцию — выбор вручную. Нужен интернет для первой загрузки модели.
- Калорийность казахских блюд в быстрых продуктах — ориентировочная, перед использованием сверить с диетологом.
- Данные хранятся только в браузере пользователя.
